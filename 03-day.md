# Power BI – Connecting to Different Data Sources

## 📌 What I Learned Today

Today I learned how to connect **Power BI Desktop** with different types of data sources and understand how data is imported into Power BI for analysis and reporting.

### 🔹 Data Sources I Explored

* Excel
* CSV files
* SQL Server
* MySQL
* Web
* Other available connectors through **Get Data**

### 🔹 Key Concepts Learned

* Using **Get Data** in Power BI
* Selecting the appropriate connector for a data source
* Connecting Power BI to databases
* Providing server, database, and authentication details
* Understanding the **Navigator** window
* Choosing between **Load** and **Transform Data**
* Using **Power Query** to prepare data before building reports
* Understanding that some database connectors require additional drivers/components

### 🔹 MySQL Connection

I also learned that connecting Power BI to MySQL may require **MySQL Connector/NET** to be installed.

The basic workflow is:

**MySQL Database → Connector/NET → Power BI → Power Query → Report**

### 🧠 Key Takeaway

Power BI can connect to many different data sources, allowing analysts to bring data from files, databases, web sources, and other platforms into one environment for **cleaning, transformation, analysis, and visualization**.

### 🛠️ Tools Used

* Power BI Desktop
* Power Query
* MySQL
* MySQL Workbench
* Excel
